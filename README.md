# Markovian Town — マルコフ連鎖ゲーム

**日本語** | [English](README.en.md)

マルコフ連鎖の定常分布を利用した対戦ゲームです。プレイヤーは道の重みを変え、自分のお店に集まる人の割合を競います。

## ルール

街はプレイヤーのお店と中立施設からなります。人々は矢印に沿って移動し、同じ場所から出る道では、重みが大きいほど選ばれやすくなります。

1. 矢印、または「出発点」「行き先」のメニューで道を選びます。
2. 重みを1増減するごとに1ポイント使います。複数の道を変更できます。
3. 全員が提出すると変更が同時に反映され、新しい定常分布から得点が計算されます。
4. 指定のラウンド数を終えた時点で、自分のお店の割合が最も高いプレイヤーが勝ちます。得点は累積しません。

作戦中の盤面には定常分布を表示します。ラウンド間は前の分布から新しい定常分布への収束を観察できます。重み0の辺も破線から選択できます。

提出前は変更を取り消せます。ポイントを残して提出することもできますが、余りは持ち越しません。同じ道への変更は合算し、重みが負になる場合は0にします。

ラウンド後は辺の増減・得点差・人の流れを確認できます。提出前のプレビューには自分の変更だけが反映されます。

## 数学的背景

### マルコフ連鎖

場所 $i$ から $j$ への道の重みを $w_{ij}$ とし、移動確率を

$$
P_{ij}=\frac{w_{ij}+\varepsilon}{\sum_k(w_{ik}+\varepsilon)},\qquad \varepsilon=0.01
$$

で定めます。重み0の道や自己ループも含め、全ての重みに $\varepsilon$ を加えます。遷移行列 $P$ の各行の合計は1です。

次の行き先の確率が現在位置だけで決まる、この移動のモデルが**マルコフ連鎖**です。各場所にいる割合を行ベクトル $x_t$ で表すと、1ステップ後は

$$
x_{t+1}=x_tP
$$

となります。

### 定常分布と固定点

**定常分布** $\pi$ は

$$
\pi P=\pi,\qquad \sum_i\pi_i=1,\qquad \pi_i\geq0
$$

を満たす分布です。写像 $x\mapsto xP$ の**固定点**であり、$P$ の固有値1に対応する左固有ベクトルでもあります。全ての $P_{ij}$ が正なので、定常分布は一意で、どの初期分布からもそこへ収束します。

お店に対応する $\pi_i$ が得点です。中立施設にも人がいるため、プレイヤーだけの合計は100%になりません。定常分布でも人は動き続けます。画面の80個の点はランダムな移動の標本、ノードの円弧と数値は計算した分布を表します。

### PageRank

場所をウェブページ、道をリンクと考えると、定常分布をページの重要さとみなすPageRankにつながります。実験室では、確率 $\alpha$ で道をたどり、残りの確率で全ての場所から均等に選んだ場所へジャンプするモデルを試せます。

$$
P_\alpha=\alpha P+(1-\alpha)U,\qquad U_{ij}=\frac{1}{n}.
$$

$n$ は場所の総数です。$\alpha=0.85$ なら15%の確率でジャンプし、$\alpha=0$ なら分布は1ステップで均等になります。通常の対戦は $\alpha=1$ です。重みに $\varepsilon$ を加える操作と、一定確率でジャンプする操作は異なります。

参考：[CS50 — PageRank](https://cs50.harvard.edu/ai/projects/2/pagerank/)

## 教育的なねらい

予想・操作・観察・説明を通じて、次の関係を理解することを目指します。

| 学ぶこと                               | 実験例                                                     |
| -------------------------------------- | ---------------------------------------------------------- |
| 重みと確率、局所的な変更と全体への影響 | 道を1本強くし、移動確率と各店の得点の変化を比較する        |
| 個々のランダムな動きと全体の分布       | 動く点の人数のばらつきと、ノード上の割合を比較する         |
| 定常分布への収束                       | 同じ盤面で初期分布だけを変えて再生する                     |
| 固定点                                 | 「定常分布 π から」を選び、1ステップ動かす                 |
| PageRankとのつながり                   | ジャンプの確率を変え、自己ループに人が集まる状況を比較する |

授業の例（20分）：ルールと予想3分、対戦7分、初期分布の比較5分、PageRankと振り返り5分。アプリ内の「学ぶ」にも解説と話し合いの問いがあります。
